## About the Game
Threads Of Time is an educational game where the player travels to different places in Bhutan and learns about their history and geography.

The game allows players to explore different locations and complete tasks to unlock new areas. It focuses on learning through exploration and interaction.

---

## Theme
Journey through different eras and places of Bhutan

---

## Subject Integration
The game includes:
- History (culture, traditions, and important events)  
- Geography (landscape, locations, and natural hazards)  

---

## Game Concept
At the start of the game, the player sees a map of Bhutan. The player can choose a place such as Thimphu or Dagana.

Each location has tasks that must be completed. After completing the tasks, the player can unlock new places and continue exploring.

The game is designed to help players learn more about important and meaningful places in Bhutan.

---

## Learning Objectives
- Understand the history of Bhutan  
- Apply knowledge to complete tasks  
- Improve memory and recall skills  

---

## How the Game Works
- The player selects a place from the Bhutan map  
- Tasks are given based on the selected location  
- The player must complete tasks to progress  
- New locations are unlocked after completing levels  
- The player learns information about each place  

At the end of each level:
- Practice questions are given  
- These help improve memory and understanding  

---

## Features
- Map-based navigation  
- Location-based tasks  
- Level unlocking system  
- Practice questions after each level
